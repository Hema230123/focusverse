# 🌱 FocusVerse

FocusVerse is a gamified productivity and focus application built using Python and CustomTkinter.

The goal of FocusVerse is to help users stay focused, build consistency, and make productivity feel rewarding through achievements, streaks, motivation, and virtual plant growth.

## ✨ Features

- ⏳ Focus timer (25 / 45 / 60 mins)
- 🌱 Virtual plant growth system
- 🔥 Streak tracking
- ⭐ Focus points system
- 🏆 Achievement system
- 🌙 Night Owl rare achievement
- ☀️ Early Bird rare achievement
- ⚡ Marathoner achievement
- 🔔 Motivation notifications
- 🎖️ Badge unlock system

## 🛠️ Tech Stack

- Python
- CustomTkinter
- JSON (Data Storage)
